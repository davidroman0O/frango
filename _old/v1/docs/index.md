# Frango Documentation

Frango is a powerful middleware for integrating PHP scripts into Go applications. It enables you to leverage PHP for rapid view development while maintaining the performance and concurrency benefits of Go.

## Documentation Sections

- [Quick Start](quick-start.md) - Get up and running with Frango
- [Core Integration](core-integration.md) - Learn about key integration points between Go and PHP
- [PHP Access Patterns](php-access.md) - How PHP scripts access request data
- [File Upload Handling](file-uploads.md) - Working with file uploads
- [Examples](examples.md) - Complete working examples

## Key Features

- Run PHP scripts from Go HTTP handlers
- Pass data between Go and PHP
- Access HTTP request data from PHP
- Process forms and file uploads
- Virtual file system for PHP scripts
- Support for embedded PHP files
- Path parameter extraction
- JSON request/response handling
